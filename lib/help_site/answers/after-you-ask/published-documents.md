short: A released file can be checked, redacted and published as a document.

When a reply has files, you can publish them as documents after checking
them. A [[published document]] has its own page and can be searched.

The software is free. Read more about it at
[the project's page](https://github.com/FOIMonkey/nedervetil-app).
